description: Review a pull request with Witness, or drill into one hunk
argument-hint: <pr> | explain <hunk> | paths <hunk>
---

Use the `witness` skill and the `witness` MCP server.

- `/witness <pr>`: analyse the pull request, show the overview first, then page through the hunk notes.
- `/witness explain <hunk>`: explain one hunk, citing its findings.
- `/witness paths <hunk>`: show the value paths behind one hunk, with their exact lines.

Arguments: $ARGUMENTS
